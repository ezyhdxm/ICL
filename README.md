# ICL Project: In-Context Learning through Markovian Tasks

This repository investigates the emergence of in-context learning (ICL) capabilities in transformers through various Markovian tasks and the lens of task vectors. 
This README.md file is generated by [Claude Code](https://docs.anthropic.com/en/docs/claude-code/quickstart). 

## 🚀 Quick Start

This project uses [uv](https://docs.astral.sh/uv/) for fast Python package management.

```bash
# Install dependencies
uv sync

# Run experiments
uv run python src/scripts/run_exp.py

# Start Jupyter for interactive analysis
uv run jupyter lab

# Organize experimental results
uv run python scripts/organize_results.py summary
```

## 📊 Experiment Types

- **Coin Flipping**: Simple binary prediction tasks
- **Dyck Languages**: Nested bracket matching
- **Latent Models**: Hidden state Markov chains
- **Linear Regression**: In-context linear learning
- **Mixture Models**: Gaussian mixture regression
- **Repetition**: Pattern repetition tasks
- **Reversion**: Sequence reversal tasks
- **Single Index**: Single index model regression

## 🔧 Results Management

The project includes a comprehensive results organization system:

```bash
# Generate experiment summary report
uv run python scripts/organize_results.py summary

# Create shareable archive (excluding large checkpoints)
uv run python scripts/organize_results.py archive

# Create full backup with checkpoints
uv run python scripts/organize_results.py archive --include-checkpoints

# Extract figures for papers/presentations
uv run python scripts/organize_results.py figures

# Clean old experiments (keep 5 most recent per task)
uv run python scripts/organize_results.py clean --keep-recent 5
```
